## 🚀 使用方法

### 1️⃣ 选择视频组
根据需求选择对应组别：
- **白色衣服组** (`white_outfit/`)：适合清新、正式风格
- **蓝色衣服组** (`blue_outfit/`)：适合专业、商务风格

### 2️⃣ 声音克隆
- 使用 `audio/reference_audio_10s.wav` 进行声音克隆
- 黑狐要求：参考音频需5-14秒，本音频为10秒

### 3️⃣ 视频生成
- 在黑狐智能体中绑定选定的视频组
- 系统会根据克隆的声音自动生成数字人视频
