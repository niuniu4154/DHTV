## 🎯 使用说明

### 在黑狐智能体中使用

1. **选择视频组**：根据需要选择白色或蓝色衣服组
2. **获取视频地址**：
   - 白色衣服组：`https://github.com/niuniu4154/DHTV/tree/main/videos/white_outfit`
   - 深蓝色衣服组：`https://github.com/niuniu4154/DHTV/tree/main/videos/blue_outfit`

3. **配置智能体**：在黑狐平台配置时，指定对应的视频文件路径

### 视频特点

- ✅ 所有视频均包含原始音频
- ✅ 视频已按人物服装分类
- ✅ 支持多人使用不同组别
- ✅ 高清画质（大部分为 1080x1920）
